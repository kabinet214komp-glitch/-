# «Білім берудегі цифрлық технологиялар» электрондық оқулығы

Қазақ тіліндегі университеттік оқу ресурсы. Оқулық жеті мазмұнды тарауды, интерактивті тесттерді, түсіндірмелі глоссарийді, сабақ жоспары үлгісін, алты практикалық жұмысты және ресми электрондық ресурстар тізімін қамтиды.

## Жергілікті іске қосу

1. `index.html`, `styles.css`, `content.js`, `content-enhancements.js`, `script.js` және `brand-mark.svg` файлдарын бір қалтада сақтаңыз.
2. `index.html` файлын қазіргі браузерде тікелей ашыңыз. Негізгі оқулыққа Node.js, жинақтау командасы, сервер, API кілті немесе аккаунт қажет емес.
3. Барлық мазмұн жүктелмесе, `index.html` ішінде `content.js`, `content-enhancements.js`, `script.js` реті сақталғанын және барлық файл бір қалтада екенін тексеріңіз.

## Пайдалану

Сол жақ мәзірден тарау мен ішкі бөлімді таңдаңыз. Әр тараудың соңында бес сұрағы бар тест, түсіндірмелі жауаптар және дұрыс жауаптарды шолу беріледі. Екінші тарауда әр технология бөліміне шағын білім тексеруі қосылған. Қорытынды емтиханда 23 сұрақ бар. Глоссарийден термин мен анықтаманы іздеуге немесе әліпби бойынша сүзуге болады. Сабақ жоспарының өрістерін толтырғанда алдын ала қарау бірден жаңарады. Практикалық жұмыстардағы чек-парақтар мен интерактивті кейстерді пайдаланыңыз.

Жоғарғы панельде оқулықтан іздеу, қою тақырып және алаңдатпай оқу режимі бар. Баптаулар бөлімінде қаріп көлемін өзгертуге болады. Тараудағы «Бетбелгі» батырмасымен оқу бөлімін сақтаңыз. Прогресс, тест нәтижелері, бетбелгілер, оқу баптаулары, практикалық чек-парақтар мен сабақ жоспары осы браузердің `localStorage` жадында сақталады; басқа құрылғыға синхрондалмайды. Браузер деректерін тазаласаңыз, жергілікті сақтау жазбалары өшеді.

## Интернет және сыртқы платформалар

Негізгі оқулық интернетсіз ашылады. UNESCO, Creative Commons және Moodle, Google Classroom, Microsoft Teams, Kahoot!, Wayground (бұрынғы Quizizz), Canva, LearningApps, H5P сияқты сыртқы ресми ресурстарға өту үшін интернет қажет. Оқулық бұл сервистерге техникалық түрде кіріктірілмеген. Олардың қолжетімділігі, аккаунт/жазылым талабы және құпиялық шарттары өзгеруі мүмкін; қолданар алдында ресми беттерінен тексеріңіз. Inter веб-қарпі жүктелмесе, жүйелік sans-serif қаріп қолданылады.

## Жоба файлдары

- `index.html` — семантикалық интерфейс, бет құрылымы және жергілікті фавикон сілтемесі.
- `brand-mark.svg` — оқулықтың кітап-пиксель белгісі; сайттың фавиконы және WebDev платформасының логотипі.
- `ku-logo.jpg` — титул бетіндегі университет логотипі.
- `title-bg.svg` — титул бетінің фондық суреті (цифрлық технологиялар: ноутбук, планшет, бұлт, желі). Өз фотоңызды қолдану үшін `title-bg.jpg` атты файлды `index.html` жанына қойыңыз: ол автоматты түрде SVG-ді алмастырады.
- `styles.css` — көк-ақ-күлгін дизайн, бейімделетін орналасу және интерактив элементтер стилі.
- `content.js` — негізгі тараулар, глоссарий және бастапқы бағалау деректері.
- `content-enhancements.js` — жеті технология бөлімі, сапа чек-парағы, қосымша оқу материалдары және алты тапсырманың толық нұсқасы.
- `script.js` — навигация, іздеу, бағалау, жергілікті сақтау және интерфейс әрекеттері.

Оқу нәтижелері сыртқы серверге жіберілмейді; браузерлік сақтау осы құрылғы мен браузер шеңберінде ғана жұмыс істейді.
